# Teste de equilíbrio dos elementos

O protótipo possui um modo temporário de teste para validar os elementos antes de liberá-los na progressão normal:

`https://concego.github.io/booga-blaster/?test=elements`

Nesse modo:

- Fogo, Água, Terra e Ar ficam disponíveis.
- Os inimigos de fixture usam 2 HP para que efeitos como empurrão e zonas possam ser observados sem derrotá-los imediatamente.
- O fluxo normal de projétil, espera, explosão, cruz e cone permanece igual.

A URL normal continua começando apenas com Fogo desbloqueado.
